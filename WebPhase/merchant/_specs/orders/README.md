# Orders

## Purpose

Order management interface. Merchants view and manage all orders from their store and marketplace.

## Key Features

- **Order list** — searchable, filterable list of all orders
- **Order details** — expandable view with full order breakdown
- **Status management** — update order status (pending, processing, shipped, delivered, cancelled)
- **Fulfillment** — mark items as shipped, add tracking numbers
- **Payment status** — view payment confirmation
- **Channel indicator** — store vs marketplace order
- **Customer info** — customer contact details
- **Shipping address** — delivery address for order
- **Refund processing** — issue refunds for items

## Data

- All orders (from store + marketplace)
- Order details (products, quantities, prices, discounts)
- Customer information
- Shipping address
- Payment status
- Fulfillment status

## Notes

Merchant-only. Orders from marketplace are included alongside store orders in one unified list.
