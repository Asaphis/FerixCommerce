# Dashboard

## Purpose

Merchant business overview dashboard. Shows key metrics and recent activity at a glance.

## Key Features

- **Revenue summary** — total revenue, today/this week/this month
- **Orders overview** — total orders, status breakdown (pending, processing, shipped, delivered)
- **Product summary** — total products, published count, low-stock warnings
- **Customer count** — total customers, new this period
- **Traffic stats** — store visitors, marketplace traffic
- **Conversion rate** — store and marketplace conversion
- **Inventory warnings** — items running low on stock
- **Recent orders** — latest order activity with quick actions
- **Recent activity** — product updates, customer actions, system alerts

## Data

- Revenue figures (by channel: store + marketplace)
- Order counts and statuses
- Product counts and statuses
- Customer metrics
- Traffic and conversion data
- Low-stock alerts

## Notes

Merchant-only. Accessible from merchant dashboard navigation.
