# Design Engine

## Purpose

Visual storefront builder for merchants to design their store without coding.

## Editor Layout

```
┌─────────────────────────────────────────────────────────────────────────┐
│ HEADER: Save | Undo | Redo | Preview | Device | AI | History | Publish │
├────────────┬──────────────────────────────────┬────────────────────────┤
│            │                                  │                        │
│ LEFT PANEL │          CENTER CANVAS           │        RIGHT PANEL     │
│            │                                  │                        │
│ Layers /   │   Visual storefront canvas      │   Properties /         │
│ Sections / │   (editable, WYSIWYG)           │   Inspector            │
│ Structure  │                                  │                        │
│            │                                  │                        │
└────────────┴──────────────────────────────────┴────────────────────────┘
```

## Key Features

- **Component library** — draggable commerce components
- **Live canvas** — WYSIWYG editing of store design
- **Properties panel** — adjust typography, colors, layout, spacing
- **Responsive editing** — Desktop / Tablet / Mobile views
- **Layer structure** — navigate and edit page sections
- **Version history** — save, preview, revert to previous versions
- **AI Design Assistant** — natural language store improvements
- **Templates** — start from professional templates
- **Preview** — view as customer would see it
- **Publish** — make design live

## Commerce Components

- Product card, product grid
- Product price, rating, image
- Add-to-cart, wishlist buttons
- Product variants selector
- Collection, category displays
- Cart summary, reviews
- Promotional banners, trust badges

## Notes

Merchant-only. Changes saved as draft. Must click Publish to go live. AI suggestions require explicit approval.
