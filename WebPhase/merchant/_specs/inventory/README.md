# Inventory

## Purpose

Inventory management. Track stock levels, manage variants, receive low-stock alerts.

## Key Features

- **Stock quantities** — per variant/SKU with real-time counts
- **Low-stock warnings** — threshold-based alerts
- **Out-of-stock indicators** — products with zero stock
- **Inventory adjustments** — manual stock increase/decrease
- **Reserved stock** — stock allocated to pending orders
- **Import/export** — bulk stock updates via CSV
- **Stock history** — changes over time

## Data

- Variant inventory levels
- SKU information
- Stock adjustment history
- Threshold settings

## Notes

Merchant-only. Syncs with product data. Stock updates affect both store and marketplace visibility.
