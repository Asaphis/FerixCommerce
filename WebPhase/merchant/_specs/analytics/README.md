# Analytics

## Purpose

Business analytics dashboard. Merchants view revenue, traffic, conversion, and performance metrics.

## Key Features

- **Revenue** — total, by channel, by product, by time period
- **Orders** — count, value, conversion funnel
- **Customers** — new vs returning, retention, LTV
- **Products** — best-sellers, low performers, inventory turnover
- **Store traffic** — visitors, page views, popular pages
- **Marketplace traffic** — impressions, clicks, conversions
- **Conversion rate** — store and marketplace conversion
- **Sales by channel** — store vs marketplace breakdown
- **Sales over time** — daily, weekly, monthly trends

## Data

- Revenue data
- Order data
- Customer data
- Traffic data
- Product performance data

## Notes

Merchant-only. All analytics are specific to the merchant's store and marketplace sales.
