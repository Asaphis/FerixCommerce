# Settings Page

## Purpose

Customer account settings. Manage personal information, notification preferences, password, etc.

## Key Features

- **Profile settings** — name, email, profile picture
- **Password change** — update account password
- **Notification preferences** — email/SMS notifications
- **Privacy settings** — visibility preferences
- **Account deletion** — delete account option

## Data

- Customer profile information
- Notification preferences
- Privacy settings

## Notes

Requires authentication. Changes apply across all devices.
