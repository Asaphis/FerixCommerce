# Orders Page

## Purpose

Show customer order history and order details. Customers can view past orders, track shipments, and see order details.

## Key Features

- **Order list** — list of past orders with status, date, amount
- **Order status badges** — pending, processing, shipped, delivered, cancelled
- **Order details** — expandable view of each order
- **Tracking information** — shipping carrier and tracking number
- **Product list** — items in each order with images, names, quantities, prices
- **Reorder button** — quickly add same items to cart

## Data

- Customer order history
- Order details (products, quantities, prices, discounts)
- Shipping information and tracking
- Payment status

## Notes

Requires authentication. Shows only orders belonging to the logged-in customer.
