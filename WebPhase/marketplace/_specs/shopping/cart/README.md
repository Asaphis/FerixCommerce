# Cart Page

## Purpose

Shopping cart displaying products selected for purchase. Supports multi-merchant items grouped by merchant.

## Key Features

- **Product list** — all items in cart with images, names, prices, quantities
- **Merchant grouping** — items grouped by seller merchant
- **Quantity adjustment** — change quantities per item
- **Remove item** — remove products from cart
- **Save for later** — move items to wishlist
- **Subtotal per merchant** — cart total broken down by merchant
- **Cart total** — overall total across all merchants

## Data

- Cart items (products, quantities, merchant IDs)
- Product pricing data
- Inventory availability (real-time stock check)

## Notes

Public page accessible without login; persists via guest cart or customer account cart.
