# Search Page

## Purpose

Full marketplace search. Customers can find products, stores, and categories across all merchants.

## Key Features

- **Search field** — primary input with autocomplete suggestions
- **Search filters** — price range, category, brand, rating, in-stock
- **Sort options** — relevance, price (low-high, high-low), newest, best-selling
- **Results grid** — product cards with image, name, price, merchant, rating
- **Store results** — matching merchant stores with logo and product count
- **Category suggestions** — related categories and subcategories
- **Pagination / infinite scroll** — load more results
- **Saved searches** — for logged-in customers
- **Search history** — recent queries

## Data

- Search index of all products (name, description, tags, categories)
- Merchant store metadata
- Category hierarchy
- Product variant data (for filtering)
- Inventory status (in-stock filter)

## Notes

Public page. Results update in real-time as merchant catalogs change. Includes spelling correction and synonym handling.
