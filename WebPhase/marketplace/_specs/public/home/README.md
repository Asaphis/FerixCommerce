# Home Page

## Purpose

The marketplace homepage. Customers discover products, featured stores, and collections upon arrival.

## Key Features

- **Search bar** — primary search entry point
- **Featured products** — promoted items from top merchants
- **Featured stores** — highlighted merchant storefronts
- **Top categories** — browse by category tiles
- **Collections** — curated product collections
- **Marketplace promotions** — banner sections for sales/campaigns
- **Recommended products** — AI-driven recommendations
- **New arrivals** — recently added products

## Data

- Hero banner (configurable by admin)
- Product carousel (featured)
- Store carousel (featured lists)
- Category grid (with images)
- Collection sections
- Promotional banners

## Notes

This is a public page — no authentication required. Accessible to all visitors including anonymous users.
