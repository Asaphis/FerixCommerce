# Addresses Page

## Purpose

Manage customer shipping addresses. Customers can view, add, edit, and delete saved addresses.

## Key Features

- **Address list** — saved addresses with labels (Home, Work, etc.)
- **Add new address** — form to add new shipping address
- **Edit address** — modify existing addresses
- **Delete address** — remove saved addresses
- **Default address** — set primary shipping address

## Data

- Customer's saved addresses
- Address details (recipient, street, city, state, zip, phone)

## Notes

Requires authentication. Used during checkout process.
