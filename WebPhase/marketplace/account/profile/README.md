# Account Dashboard

## Purpose

Customer account dashboard. Shows order summary, wishlist items, recent activity, account settings link.

## Key Features

- **Order summary** — recent orders with status badges
- **Wishlist count** — number of saved items
- **Address count** — number of saved addresses
- **Account info** — name, email, profile pic
- **Quick links** — Orders, Wishlist, Addresses, Settings

## Data

- Customer profile data
- Recent orders (last 5-10)
- Wishlist item count
- Saved address count

## Notes

Requires authentication. Accessible from navigation bar after login.
