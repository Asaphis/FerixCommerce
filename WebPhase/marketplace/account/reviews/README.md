# Reviews Page

## Purpose

Customer reviews section. Customers can view their submitted reviews and manage them.

## Key Features

- **Review list** — customer's submitted reviews with ratings
- **Edit review** — modify existing reviews
- **Delete review** — remove reviews
- **View product** — link to reviewed product

## Data

- Customer's submitted reviews (product ratings, text)
- Review dates

## Notes

Requires authentication. Shows only the logged-in customer's reviews.
