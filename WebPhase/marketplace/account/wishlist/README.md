# Wishlist Page

## Purpose

Show customer's saved products. Customers can view and manage products they have saved for later.

## Key Features

- **Saved products list** — grid of saved products with image, name, price
- **Remove from wishlist** — remove saved items
- **Add to cart** — quickly add saved items to cart
- **Product details** — link to product page

## Data

- Customer's saved products
- Product images, names, prices, ratings

## Notes

Requires authentication. Syncs across devices for logged-in customers.
