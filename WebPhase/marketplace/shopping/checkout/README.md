# Checkout Page

## Purpose

Multi-step checkout flow. Customers enter shipping, select delivery method, and pay.

## Key Features

- **Step 1: Shipping Address** — select or add delivery address
- **Step 2: Shipping Options** — choose delivery method and cost
- **Step 3: Payment** — select payment method (card, wallet, etc.)
- **Step 4: Review Order** — final order summary with all merchants
- **Order confirmation** — order number and details shown

## Data

- Customer's saved addresses
- Shipping options and costs
- Payment methods
- Order items (grouped by merchant)
- Taxes and discounts
- Total amounts

## Notes

Requires login to complete checkout. Items from multiple merchants are shipped separately but purchased together.
