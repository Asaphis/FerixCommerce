# Stores Discovery Page

## Purpose

Browse and discover merchant stores on the marketplace. Customers can find stores by category, rating, or search.

## Key Features

- **Store cards** — logo, name, rating, product count, category badges
- **Store search** — search stores by name
- **Category filters** — filter stores by product categories
- **Sort options** — top-rated, most products, newest
- **Featured stores** — promoted by admin
- **Follow button** — logged-in customers can follow stores

## Data

- Store metadata (name, logo, banner, description)
- Store ratings
- Product count per store
- Store categories
- Follow count

## Notes

Public page. Only stores with "Marketplace participation" enabled appear here.
