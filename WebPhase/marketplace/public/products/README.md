# Product Page

## Purpose

Display detailed information about a specific product. Customers can view images, variants, price, reviews, and add to cart.

## Key Features

- **Main product images** — carousel or gallery
- **Product name** — prominent display
- **Price** — with discount badge if applicable
- **Product variants** — selectable options (size, color, etc.)
- **Product rating** — stars and numerical rating
- **Reviews section** — customer reviews and ratings
- **Add to cart button** — primary action
- **Wishlist button** — save for later
- **Related products** — similar items or same merchant
- **Product variants** — selectable options (size, color, etc.)

## Data

- Product ID and SKU
- Product name and description
- Main images (multiple)
- Product variants (each with price, stock, SKU)
- Pricing information (base price, discount, final price)
- Customer ratings and reviews
- Merchant information
- Inventory status (in-stock, out-of-stock)
- SEO metadata (title, description, URL slug)

## Notes

Public page. Accessible to all visitors. Requires product to be published and visible on marketplace or merchant storefront.
