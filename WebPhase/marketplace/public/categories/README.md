# Categories Page

## Purpose

Browse products by category. Shows category information, subcategories, and products within the category.

## Key Features

- **Category details** — name, description, image
- **Subcategory navigation** — drill-down into subcategories
- **Product grid** — products in this category
- **Category filters** — price, brand, rating, in-stock
- **Sorting** — relevance, price, newest, best-selling
- **Featured products** — highlighted within category
- **Parent category breadcrumb** — navigate up the hierarchy

## Data

- Category tree structure
- Products mapped to categories
- Subcategory relationships
- Product images, names, prices, ratings

## Notes

Public page. Categories are configured by admin. Merchants assign their products to categories.
