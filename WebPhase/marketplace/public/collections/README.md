# Collections Page

## Purpose

Browse curated product collections on the marketplace. Collections are curated sets of products grouped by theme, category, or promotion.

## Key Features

- **Collection cards** — image, name, description, product count
- **Collection search** — search by collection name
- **Category filters** — filter collections by category
- **Sort options** — most popular, newest, most products

## Data

- Collection metadata (name, description, image, featured products)
- Product assignments per collection
- Collection categories
- Collection visibility (admin-controlled)

## Notes

Public page. Collections are configured by admin and/or merchants (merchant collections).
